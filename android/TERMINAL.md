# SSH 终端

从「服务器」首页点击「打开终端」，进入独立的全屏 SSH 会话。终端无需配套服务端；使用连接配置中已核验的服务器身份，支持 PTY、ANSI/全屏程序、UTF-8、方向键、Tab、Ctrl 组合键、粘贴、字号调整和横屏。

## 连接与授权

在服务器页首次授权时，可同时启用终端免密连接；服务访问和终端各自使用独立密钥，密码只用于当次授权，不保存。终端密钥拥有该 SSH 账户的命令执行权限，不允许 agent、端口和 X11 转发。

先从终端登录时，「记住此设备」默认开启；之后服务器页可以复用此密钥登记服务权限，无需再次输入密码。取消记住设备则只登录本次。已有授权在重连时直接使用密钥；网络中断不会清除授权。

## 键盘与交互

终端上方的输入方式入口可切换「内置模拟键盘」和「系统输入法」，选择会保存。「键盘 / 收起」控制当前键盘的展开与隐藏。

内置键盘使用错列 QWERTY 布局，支持 Shift、大写锁定、空格、退格和回车，不调起系统输入法。123 / #+= 切换数字与符号，覆盖 ASCII 标点。长按 Shift 锁定大写，长按退格连续删除。横屏时内置键盘放在输出区右侧，切换和旋转都保留 SSH 会话。中文输入可切回系统输入法。

Fn 切换 F1–F12、Insert/Delete、Home/End、翻页和 Shift+Tab，再次点击返回原键盘页。功能键支持 Ctrl / Alt 组合，Ctrl+/ 发送与 Ctrl+_ 相同的控制字符。

底部功能键提供 Esc、Tab、Ctrl、Alt、方向键、Home、End 和翻页。Ctrl / Alt 点击单次启用、长按锁定；音量下键也可作为 Ctrl。方向键和翻页键支持长按连发，长按减号输入竖线。

滑动按当前程序模式处理：普通 shell 浏览本地历史，鼠标模式发送滚轮事件，无鼠标模式的全屏应用发送方向键。tmux 滚动历史需启用 `set -g mouse on`；App 不修改服务器上的 tmux 配置。同一次滑动的鼠标坐标固定在起点，避免误滚动相邻窗格。

双指缩放调整字号；长按文字可选择、拖动选区并复制。粘贴多行或控制字符前需要确认。返回先取消选区或收起键盘，再选择后台运行或结束当前会话。

终端只加载 APK 内资源，不持久化输出，禁止截图和最近任务预览。主动断开会关闭 SSH shell；需要持续运行的任务应由服务器上的 tmux、screen 或 systemd 管理。

## 后台会话

已连接的终端由前台服务维持，锁屏、切换应用和页面重建保留同一个 SSH 会话及终端内容。返回时选择「后台运行」可以继续使用 App 的其他模块；通过终端入口或常驻通知回到原会话，通知也提供断开操作。

CPU 与 Wi-Fi 唤醒锁仅在终端会话活动期间持有，断开后释放。通知不显示服务器地址或终端输出，拒绝通知权限不会阻止连接。强制停止、部分厂商后台限制、深度省电或网络切换仍可能中断 SSH；App 不会自动重连并重发命令。
