# 发布前安全审查

审查日期：2026-10-03。范围为本仓库当前源码、提取的 14 个历史提交、Android 安装包构建、受限 SSH 网关、终端授权、服务端认证、部署脚本和 CI。

## 隐私与凭据

- Gitleaks 8.30.1 检查完整提取历史及待发布文件。历史的 6 条告警均为 xterm 压缩代码的 `FourKeyMap` / `SequencerByKey` 变量误报；已复核源码，并由固定版本上游包重建确认当前终端资源字节一致。未发现实际 token、密码或私钥。
- 源码与历史没有个人服务器地址、服务器账户、部署 Gist ID、固定管理员公钥、签名 keystore 或运行数据库。示例仅使用占位值，测试使用隔离环境和临时凭据。
- 保留公开的 GitHub 作者身份，但将提取历史中的真实邮箱替换为 GitHub 隐藏邮箱。现有 APK 签名证书的公开作者标识保留以兼容覆盖安装；它不是服务器账户，签名私钥不进入源码或构建产物。
- Android 不包含 GitHub 写入凭据；SSH 密码仅用于当次登录，不写入配置或日志，设备私钥由 Android Keystore 生成并保管。

## 认证与命令执行

人工检查未发现预置后门账户、隐藏授权密钥、跳过认证的管理路由或向第三方上传用户数据的代码。

- SSH 登录严格验证已确认的主机密钥。首次指纹发现不发送登录凭据，需用户核验。
- 想法设备密钥使用 `restrict` 与固定强制命令；网关按服务端能力和路由白名单授权，不执行客户端传入的 shell 命令。每次 RPC 的内部会话会清理。
- 终端明确拥有配置账户的 shell 权限；专用密钥只在用户勾选登记后写入服务器，和想法密钥分开；不启用 agent、端口或 X11 转发。
- API 默认仅监听回环地址，管理、导出、状态和发布均需认证。Web 登录没有预置密码，具备限速与来源校验。Gist 发布只包含想法记录，不包含会话、配置或凭据。
- 终端 WebView 仅加载 APK 内的固定资源，禁止网络、文件和 content URI 访问，禁止外链跳转与 OSC 52 剪贴板写入。终端和密码窗口禁止截图。

## 依赖与 CI

- 本次 pip-audit 对安装后的 Python 依赖扫描未报告已知漏洞；GitHub Advisory Database 对 JSch 2.28.7、xterm 6.0.0 和 addon-fit 0.11.0 的查询未返回匹配公告。
- JSch 下载与终端资源有固定版本和校验值。GitHub Actions 固定到完整提交 SHA；工作流仅有 `contents: read`，checkout 不保留 Git 凭据。
- 只有主线可使用正式签名 secrets；分支与 PR 使用独立预览签名。签名文件不上传 artifact，任务末尾清理临时文件。
- 原生测试使用一次性 SSH 环境，不访问生产服务器或写入生产 Gist。

## 验证及边界

后端认证、CSRF、受限路由、服务端能力校验、密钥撤销和内部会话清理已有测试覆盖。终端有主机身份、授权分离、WebView 隔离和交互测试。

此记录描述本次检查结果，不保证不存在尚未发现的漏洞。手机或 SSH 账户本身被控制后，终端授权仍可被使用；服务端 API 应继续只监听回环地址，不能因想法内容公开就开放免认证管理。

## 配置注入补充

部署 SSH 目标、Gist 目标及 token 文件路径、Android keystore 路径和签名别名均可由环境变量注入；仓库只提供无真实值的 `.env.example`。Gist 非交互配置仍强制验证所有权和权限。部署文件列表不包含本机 `.env`，App 也不从构建环境内置服务器凭据。
