# 私有收件箱

手机、电脑和服务器共用的暂存空间，支持文字、链接及一组文件。下载不会删除服务器副本；默认保留到手动删除。收件箱不发布到 Gist，也不会自动创建公开想法。

## 手机

从浏览器、相册或文件管理器选择「分享 → 发送到收件箱」。确认页显示目标服务器、文字、附件和备注，可移除附件后发送。也可在 App 的收件箱中直接新建文字或选择文件。

附件先导入 App 私有暂存区，显示导入进度；此时返回会保留已导入的草稿。发送后进入持久队列，上传成功释放本机暂存附件。未配置服务器时可以先保留草稿，配置后继续。普通分享默认进入私有收件箱，「记录想法」快捷入口仍用于公开想法。

首次使用需要 `inbox.read` 和 `inbox.write` 权限。已有终端密钥时，明确确认后可用该密钥授予本机收件箱权限，无需再次输入服务器密码；否则使用当次密码完成登记。后续传输使用受限服务密钥。

收件箱区分导入、排队、传输、已存服务器和已下载到手机。传输通知提供暂停；页面提供继续、重试和取消。任务中断后保留已传输部分，重新连接可以继续。Android 结束进程或限制长时间后台任务时，不承诺永远保持连接。

图片支持列表缩略图、点开预览、双指缩放；视频和短文本也可直接查看。大文件按需下载，小图缩略图缓存在 App 私有目录。筛选支持类型、来源、时间和排序，长按条目可批量下载或删除。

下载默认保存在 App 私有目录。要在系统相册中查看图片或视频，请在预览页的「更多」中选择「保存到相册」；普通文件可另存或转发。APK 调用系统安装器；必要时由用户开启「允许此来源安装」，返回后继续。更改服务器配置会暂停原目标的队列，不能自动改投新服务器。

## 电脑浏览器

使用电脑自己的 SSH 账户与密钥，运行：

```sh
ssh -t -o ExitOnForwardFailure=yes -L 127.0.0.1:8787:127.0.0.1:8787 my-server "~/.local/bin/myserver inbox web --port 8787"
```

将 `my-server` 替换为自己的 SSH 配置别名。打开命令打印的本机地址，粘贴本次 token 登录。网页支持拖入文件、粘贴图片、发送文字、搜索与筛选。点击附件预览，条目的更多菜单用于编辑和删除。进入选择模式可批量删除或下载 ZIP，包含附件、文字和备注；每次打包最多 32 条收件、64 个附件，「选择已加载」仅包含当前已加载的条目。图片、音视频按浏览器支持情况预览，文本始终按纯文字显示。

网页在当前登录会话中复用图片和文本预览，缓存上限为 32 MiB、32 项；列表重绘、切换筛选、重新打开或保存已预览图片不会重复下载同一份内容。关闭页面、退出登录或授权失效会清理预览缓存。大图按需读取，音视频使用浏览器分段播放，不为缓存而预下载整个文件。

也可以先在服务器运行 `~/.local/bin/myserver inbox web`，再在电脑执行 `ssh -N -L 127.0.0.1:8787:127.0.0.1:8787 my-server`。管理页只监听服务器本机，网页流量跨网络时经过 SSH 加密，无需增加安全组端口。App 服务密钥和终端密钥不提供端口转发，电脑使用已有的普通 SSH 登录权限。

默认最长运行两小时、空闲三十分钟退出，可通过 `--timeout` 和 `--idle-timeout` 修改秒数。正在传输不计为空闲。Ctrl+C 关闭入口并撤销本次登录，数据继续保留。端口被占用会报错，不接管其他进程；可以同时修改转发与命令中的端口号。

刷新页面后，需要按提示重新选择原文件才能恢复上传；会校验完整文件内容后继续。传输记录仅保留在当前标签页，关闭标签页后未完成任务需要重新发起，服务器残留的未完成上传按过期规则清理。文件内容完整校验后才进入收件列表。令牌只能用于本次收件箱管理，不是通用服务器凭据，也不是公开分享链接。

## 服务器与脚本

安装程序创建 `~/.local/bin/myserver`。若该目录未在 PATH 中，可直接使用完整路径。

```sh
myserver inbox put ./build/app.apk --note "测试安装包"
myserver inbox put ./report.pdf ./chart.png --note "本次结果"
myserver inbox put --text "https://example.com/"
printf '需要稍后处理的文字' | myserver inbox put --text -
myserver inbox list
myserver inbox list --json
myserver inbox get ITEM_ID --output ./app.apk
myserver inbox get ITEM_ID --file FILE_ID --output ./attachment.bin
```

`put` 复制稳定内容，原文件保留；源文件在操作中被改变时会校验失败，不发布不完整条目。成功输出条目信息，失败返回非零状态。`get` 拒绝覆盖已有目标。多附件条目需要用 `--file` 指定附件 ID，文字条目可直接导出为 UTF-8 文件。

## 容量与备份

默认配额 5 GiB，涵盖已完成文件与未完成上传的预留容量。空间不足时拒收，保留已有内容；未完成上传超过七天未活动后可被清理。手机分享每次最多 32 个附件，文字最多 20,000 字符、备注最多 2,000 字符。

配额通过服务器端命令持久设置：

```sh
myserver inbox configure --quota-bytes 10737418240
```

用户级每日备份包含数据库和已完成附件。手动备份、校验解包：

```sh
myserver backup-full /path/to/new-backup.tar
myserver backup-unpack /path/to/new-backup.tar /path/to/new-directory
```

目标必须不存在。解包只写入新目录并校验文件摘要，不替换运行数据；恢复流程见[服务端文档](../server/README.md)。未完成传输、本次 Web 令牌、授权文件和凭据不在完整数据归档中。

这里的私有存储指自有服务器与访问控制，服务器账户和 root 仍可读取数据；不提供端到端加密。
